# TriggerBot 1.21.4 (Fabric)

Триггербот только по игрокам + криты. Вкл/выкл на **R**.

## Как получить готовый .jar через GitHub Actions

1. Создай **новый** репозиторий на GitHub (можно приватный)
2. Залей **все файлы** из этой папки в репозиторий
3. Зайди во вкладку **Actions**
4. Нажми на workflow **Build TriggerBot** → **Run workflow**
5. Подожди 1–3 минуты
6. Когда сборка станет зелёной — зайди в неё и скачай артефакт `triggerbot-1.21.4`
7. Внутри будет `triggerbot-1.0.0.jar`

Готово. Клади в `mods` и играй.
